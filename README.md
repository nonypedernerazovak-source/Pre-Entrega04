# Pre-Entrega04
# Librería LunaBelle
# Descripción
El programa simula un pequeño sistema para la Librería LunaBelle, donde se puede:
Visualizar los libros disponibles.
Agregar libros al final de la lista.
Agregar libros al principio de la lista.
Eliminar el último libro.
Eliminar el primer libro.
Acceder a un libro mediante su índice.
Modificar un libro utilizando splice().
Recorrer la lista utilizando for...of.
Buscar un libro y verificar si existe.
Obtener la posición de un libro mediante indexOf().
## Métodos de arrays utilizados
push()
pop()
unshift()
shift()
splice()
includes()
indexOf()

## Objetivo del proyecto
El objetivo principal es poner en práctica los conceptos fundamentales de arrays en JavaScript, trabajando con:
Manipulación de elementos.
Índices.
Métodos de arrays.
Funciones.
Condicionales.
Ciclos.
Búsqueda y validación de información.
